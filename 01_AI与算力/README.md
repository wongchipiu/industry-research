# AI 与算力

## 产业主线

AI 产业的投资研究按“需求—计算—互连—内存—制造—电力—应用变现”展开：

```text
模型/应用需求
  → 云与AI工厂资本开支
    → GPU / 定制XPU / CPU
      → HBM / 先进封装 / 晶圆代工
        → 交换芯片 / 光互连 / 存储
          → 服务器 / 供配电 / 制冷
            → token成本下降、使用量增长与应用收入
```

## 当前核心论文

1. AI 基础设施仍处在强资本开支阶段，但计算架构正从单一 GPU 叙事走向 GPU、定制 XPU、CPU 和网络协同。
2. 最大利润池仍在拥有软硬件生态和系统级优化能力的平台，单芯片峰值性能不是充分条件。
3. 更低的单位 token 成本可能通过需求弹性扩大总计算量；必须同时观察使用量与单位价格，而不能只看降本。
4. 先进制程、HBM、先进封装、网络和电力都是系统瓶颈，瓶颈迁移决定超额利润迁移。
5. 资本开支最终必须由云收入、广告效率、订阅和企业生产率变现，否则折旧压力将反噬估值。
