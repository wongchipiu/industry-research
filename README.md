这是一个持续更新的行业研究系统，目标不是收藏资讯，而是把产业事实转化为可验证的投资判断。

## 目录约定

- `00_总规划`：目标、方法、路线图、维护规则
- `01`—`08`：按产业主题沉淀长期知识
- `90_每日研究`：每天新增一份带日期的研究报告
- `91_投资标的库`：跨市场公司池、评分与跟踪状态
- `92_信号与事件`：高频指标、催化剂、风险和论文证伪
- `99_模板`：保证不同日期和行业之间可比较

## 使用方式

1. 先阅读总规划和方法论。
2. 每日从 `90_每日研究/INDEX.md` 进入当日研究。
3. 看懂行业后，再进入对应主题目录阅读产业地图和公司卡片。
4. 所有投资判断都应同时写明“关键假设、触发条件、证伪条件和数据日期”。
5. 报告文件统一使用“日期_时间_主题域_细分主题_类型_版本”命名，生成时间与数据截止时间分开记录。

> 本知识库用于研究和决策支持，不构成个性化证券投资建议。价格、估值和政策信息具有时效性，交易前需复核。
